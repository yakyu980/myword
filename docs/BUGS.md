### LocalStorage מלא

* **סטטוס:** `[פתוח]`
* **תסריט:** מסמך גדול עם תמונות base64 רבות
* **תופעה:** שמירה נכשלת בשקט — מוצגת הודעה `✗ אין מקום ב-localStorage`
* **סיבה:** תמונות נשמרות כ-base64 מה שמנפח מאוד את הנפח
* **קוד:**

```js
catch (e) { setSaveState('unsaved', '✗ אין מקום ב-localStorage'); }
```

* **Workaround:** ייצא כ-HTML לפני שהמסמך גדל מדי

### Undo לא מחזיר אובייקטים חופשיים

* **סטטוס:** `[פתוח — by design]`
* **תסריט:** גרירת תמונה → Ctrl+Z
* **תופעה:** Undo מחזיר טקסט אבל לא מיקום תמונות/תיבות טקסט
* **סיבה:** undo/redo עובד דרך execCommand (היסטוריית הדפדפן) — לא כולל שינויי DOM ישירים של `.free-obj`
* **קוד:**

```js
// undo/redo מוגן — לא נוגע ב-free-obj
if (cmd === 'undo' || cmd === 'redo') {
  const objs = [...editor.querySelectorAll('.free-obj')];
  document.execCommand(cmd);
  objs.forEach(o => { if (!o.isConnected) editor.appendChild(o); });
}
```

* **Workaround:** אין — הימנע מגרירות לאחר עריכת טקסט חשובה

### מחשבון — סמלים מתמטיים מקושקשים (mojibake)

* **סטטוס:** `[תוקן — 2026-06-23]`
* **תסריט:** פתיחת מחשבון (סרגל הוספה) → צפייה בכפתורי הפעולות / הרצת חישוב
* **תופעה:** סמלים הוצגו כ-mojibake: `÷→ֳ·`, `×→ֳ—`, `−→גˆ’`, `∛→גˆ›`, `π→ֿ€`, `±→ֲ±`, `²→ֲ²`, `³→ֲ³`, `·→ֲ·`, `Δ→־"`, `γ→־³`. גם בתצוגת הנוסחה/שלבים וגיאומטריה/פיזיקה
* **סיבה:** תווי UTF-8 נשמרו בקובץ כ-Windows-1255 (double-encoding) — מקומי למחשבון בלבד. החישוב עצמו תקין (data-op ב-ASCII)
* **תיקון:** החלפת 11 טוקני-mojibake בסמלי Unicode הנכונים (replace_all). נאמת חי: כל הכפתורים תקינים, `9 × 6 = 54`, אפס שגיאות. **הערה לבדיקה:** Chrome מטמן HTTP — לאמת עם `?v=` cache-buster, ולוודא קודם שהקובץ-בדיסק תוקן (grep) לפני להאשים את OneDrive

* **תיקון:** הלוגיקה הועברה ל-`_onGlobalMove(e)`; עטיפה מרסנת ב-`requestAnimationFrame` (מאחדת אירועים לפריים), מדלגת כשאין גרירה/שינוי/סיבוב. `_flushGlobalMove()` ב-mouseup → מיקום סופי מדויק. נאמת חי: throttleDefersWork + dragAppliesOnFlush

### תוכן מסמך נטען ללא ניקוי-אבטחה (sec)

* **סטטוס:** `[תוקן — 2026-06-23]`
* **תסריט:** טעינת מסמך (`editor.innerHTML = d.content`)
* **תופעה:** תוכן נטען מ-innerHTML בלי סינון תוכן פעיל (defense-in-depth; סיכון נמוך — localStorage עצמי)
* **תיקון:** `_sanitizeStored(html)` — מסיר רק תוכן מסוכן (script/iframe/object/embed/on*-handlers/javascript:) ו**משמר את כל העיצוב** (style/class/data/base64/טבלאות). לא מחטא-ההדבקה (שמסיר עיצוב). free-objs אינם ב-content (ה-wrapper מסירם). נאמת חי: 9 בדיקות ירוקות (מסוכן מוסר, עיצוב נשמר)

## 🟢 נמוך (מציק אבל לא חוסם)

### עטיפת טקסט (float) סביב טבלה — פיצ'ר חדש (1.9)

* **סטטוס:** `[נוסף — 2026-06-24]`
* **תסריט:** לחיצה בתא טבלה → כפתור "עטיפת טקסט" בסרגל הצף
* **מה נוסף:** מחזור 3 מצבים — **בלוק** (רוחב מלא) → **עוטף ימין** (`float:right`, 50%) → **עוטף שמאל** (`float:left`) → בלוק. הטקסט עוטף לצד הטבלה כמו Word
* **מימוש:** `_setTableWrap(table, mode)` — float+width+margin בזרם (לא absolute), `data-wrap` מסמן; מבטל מצב גרירה-חופשית. CSS אייקון `SIC.wrap`
* **היקף מינימלי-בטוח:** טבלה עוטפת מוחרגת מפיצול-שורות (`_paginateTables` בודק `!dataset.wrap`); אם גבוהה מעמוד — `paginateBlocks` דוחף שלמה (לא מפצל). **לא נגעתי ב-pagination הגלובלי**
* **אומת חי:** float-right/left עוטף טקסט (Range: שורת-טקסט x=137-209 לצד טבלה x=397-699), block משחזר רוחב-מלא, serialization שורד (data-wrap ב-innerHTML), 0 הפרות אזור-פער, טבלה רגילה עדיין מתפצלת (60 שורות→2 spacers), 0 שגיאות

### יציאה מרשימה (Enter על פריט ריק) השאירה markup מלוכלך

* **סטטוס:** `[תוקן — 2026-06-24]`
* **תסריט:** רשימה → Enter על פריט ריק (כדי לצאת מהרשימה כמו Word)
* **תופעה:** יצא מהרשימה, אבל השאיר `<span style="font-size"><div><span><br></span></div><br></span>` במקום `<p><br></p>` נקי
* **סיבה:** `execCommand('outdent')` + `execCommand('insertParagraph')` — התנהגות דפדפן לא-עקבית שעוטפת ב-div/span
* **תיקון:** מניפולציית DOM נקייה (handler ~11484): מסיר את ה-LI הריק, מכניס `<p><br></p>` נקי, מפצל רשימה אם יש פריטים אחרי (OL — המספור ממשיך עם `start`), LI מקונן → outdent רמה אחת. נאמת חי 4 מקרים (סוף/אמצע/מקונן/יחיד) + רגרסיה (Enter על פריט עם תוכן לא נחטף) + 0 שגיאות

### גרירת תמונה במצב "בשורה" (inline) הטיחה אותה הרחק

* **סטטוס:** `[תוקן — 2026-06-23]`
* **תסריט:** תמונה במצב "בשורה" → גרירה כדי למקם אותה בין שורות/פסקאות
* **תופעה:** התמונה ניתקה ממקומה וקפצה ~435px ימינה + 302px למטה מחוץ לזרם
* **סיבה:** inline הוא `position:relative` ללא left/top, אך הגרירה השתמשה במסלול המוחלט (`wrap` רק ל-float). `left=offsetLeft+dx` על אלמנט יחסי = היסט ענק
* **תיקון:** דגל `_dragSt.inline`; ב-mousemove inline עובר עיגון-מחדש בזרם (`_reanchorFloat`) בלי left/top — נע בין פסקאות כמו Word. `_clamp` כבר מדלג על inline. נאמת חי: גרירה מ-לפני-pA ל-בין-pB-pC, ללא קפיצה

### תמונת גלישה לא הגיעה לגבול הימני/שמאלי המוגדר

* **סטטוס:** `[תוקן — 2026-06-23]`
* **תסריט:** תמונה במצב "עוטף ימין" → גרירה לקצה הימני של הדף
* **תופעה:** הקצה החיצוני נתקע ב-2.5cm מקצה הדף (גבול אזור-הטקסט), לא הגיע ל-1.0cm המוגדר. גם הגרירה החיה וגם `_clampFloat` רצפו את ה-margin ל-0
* **סיבה:** `Math.max(mr, 0)` חסם margin שלילי — התמונה לא יכלה להיכנס לשוליים (overflow:visible מאפשר את זה)
* **תיקון:** עוזר משותף `_floatHBounds(obj)` (מקור-אמת יחיד לגרירה ול-clamp): חיצוני `-(2.5-1.0)cm`, פנימי `contentW/2 - w + 0.2cm`. נאמת חי: FR/FL מגיעים ל-1.0cm מהקצה, פנימי 0.2cm ממרכז. ראה IMAGES.md חוק 5
* **מצב אנכי ("בין שורות"):** נבדק חי — גרירה אנכית עוקבת אחרי הסמן, snap ל-0.5cm (Alt=חופשי); מצב inline תקין. **לא נמצא כשל אנכי** — ממתין להבהרת המשתמש
