# SPEC-UX-CTXBAR-CONSISTENCY — עקביות סרגל צף בהקשרים שונים

**קטגוריה:** Consistency · UX  
**חומרה:** 🟠 גבוה (בלבול משתמש בכל החלפת הקשר)  
**מיקום ב-UI:** `#ctxBar` (סרגל צף דו-שורתי)

---

## מה קיים עכשיו

**הבעיה:** סרגל הצף שונה לחלוטין לפי הקשר:

### הקשר: בחירת טקסט (Home)
```
[צבע] [צבע רקע] [סמן] [יישור ×4] [רשימות] [עוד ▾]
```

**צורה / תמונה:**
```
[שקיפות] [ריבוד] [נעילה] [מחיקה] [בחירה מרובה] [עוד ▾]
```

**טבלה:**
```
[שורות/עמודות] [צבע תא] [יישור] [מיזוג] [עוד ▾]
```

**תיבת טקסט:**
```
[גרירה] [טאב כתיבה] [מחיקה] [בחירה מרובה] [עוד ▾]
```

## המשתמש חושב

1. **"אני בחרתי תמונה, לא מוצא את כפתור הרקע"** (הוא בעמוד-2, או בסרגל הראשי?)
2. **"בחרתי טקסט אחרי כן בחרתי צורה — סרגל הצף השתנה לגמרי!"**
3. **"איפה כפתור 'שקיפות' בתמונה? בטקסט זה לא היה…"**
4. **בעיה בהיזיכרון המיידי:** "עשרות קליקים בחזרה ל-עמוד-2 בסרגל הצף כדי למצוא את אותו הכפתור בהקשר אחר"

---

## ניתוח — מה צריך להיות זהה?

### כפתורים שצריכים להופיע בכל הקשר:

1. **שקיפות** (0-100%)
   - טקסט: לא חשוב (מעט)
   - **תמונה:** חשוב (להסתיר רקע)
   - **צורה:** חשוב (סגנון)
   - **תיבת טקסט:** חשוב (ריבון צפוף)

2. **ריבוד** (forward/backward/front/back)
   - **תמונה:** חשוב (מאחורי טקסט וכו')
   - **צורה:** חשוב (שכבות)
   - **תיבת טקסט:** חשוב (עיצוב)
   - טקסט: לא רלוונטי

3. **נעילה** (lock/unlock)
   - **תמונה:** בעמוד-2 (נדיר)
   - **צורה:** בעמוד-2 (נדיר)
   - **תיבת טקסט:** בעמוד-2 (נדיר)
   - **טבלה:** לא יש כרגע

4. **מחיקה** (delete)
   - בכל הקשר: **בעמוד-2 בלבד** (יעדינו, נמוך-תדר)

5. **בחירה מרובה** (multi-select, Shift+Click)
   - בכל הקשר אובייקט חופשי: בשורה-1 או בעמוד-2?

## הצעה — "Common Bar"

**הגדר סדר-בסיס בכל הקשרים:**

### שורה-1 (ערכים עליונים)
```
1. [שקיפות 0-100%]
2. [ריבוד: 🔼 / 🔽 / ⬆ / ⬇]
3. [כפתור עוד ▾]
```

### עמוד-2 (בתוך ▾)
```
- נעילה (lock/unlock)
- מחיקה
- [הקשר-ספציפי: צבע תא לטבלה, כלים לתיבת טקסט]
```

## ניתוח המקרים

### 1️⃣ טקסט (בית)

**שורה-1 (קיים):**
- צבע טקסט
- צבע רקע
- סמן
- יישור ×4
- רשימות

**שורה-2 (קיים):**
- עוד ▾

**עמוד-2 (קיים):**
- ניקה עיצוב
- מברשת עיצוב
- סופר
- תחתי

**עדכון:**
- הוסף `שקיפות + ריבוד` ל-שורה-1 (לא רלוונטי כאן, אבל עבור עקביות? או תצניע לעמוד-2)
- **או:** שומר כמו-זה, כי טקסט לא צריך שקיפות

### 2️⃣ תמונה

**שורה-1 (קיים ב-ctxBar):**
- שקיפות (0-100%)
- ריבוד (forward/backward)
- עוד ▾

**עמוד-2 (קיים):**
- נעילה
- מחיקה
- מאחורי הטקסט
- ... (הוסף כל הכלים מ-imgformat ribbon)

### 3️⃣ צורה

**שורה-1 (חסר!):**
- שקיפות (קיים בעמוד-2, צריך בשורה-1)
- ריבוד (קיים בעמוד-2, צריך בשורה-1)
- עוד ▾

**עמוד-2 (קיים):**
- נעילה
- מחיקה
- סגנון צורה (fill, stroke)
- ... (הוסף כל הכלים מ-shapeformat ribbon)

### 4️⃣ טבלה

**שורה-1 (קיים):**
- הוסף שורה/עמודה
- מחק
- צבע תא
- יישור
- עוד ▾

**עמוד-2 (קיים):**
- מיזוג תאים
- ... (כלים מ-table ribbon)

**עדכון:**
- הוסף `שקיפות` (לא צפויה, אך... לטבלה שקופה בחצי)
- הוסף `ריבוד` (תמיד שימושי, אפילו לטבלה)

### 5️⃣ תיבת טקסט

**שורה-1 (קיים):**
- ארגון כפתורים עבור tb-header (grab + delete)

**עמוד-2 (קיים):**
- עיצוב (border, padding, תצבע, צל)
- מחיקה

**עדכון:**
- הוסף `שקיפות + ריבוד` בשורה-1 (עקביות)
- הוסף `נעילה` בעמוד-2

## צעד-אחר-צעד

1. **בחר תמונה** → סרגל הצף: `[שקיפות] [ריבוד] [עוד]`
2. **בחר צורה** → סרגל הצף: `[שקיפות] [ריבוד] [עוד]`
3. **בחר תיבת טקסט** → סרגל הצף: `[שקיפות] [ריבוד] [עוד]`
4. **בחר טקסט** → סרגל הצף: `[צבע] [צבע רקע] [עוד]` (כי טקסט לא צריך שקיפות)

---

## השפעה צפויה

- **משתמש מעביר בין הקשרים** → מוצא את הכפתורים בעמדה **תמיד-אותה** (muscle memory)
- **"שקיפות" תמיד בשורה-1** → לא צריך לחפש בעמוד-2
- **"ריבוד" תמיד בשורה-1** → עקבי

---

## כלל הניהול

**סרגל הצף חייב להציע:**
1. **Opacity + Layering** (כמעט כל אובייקט צריך זה)
2. **Context-specific tools** (צבע טבלה, border תמונה וכו')
3. **Destruction (delete + lock)** בעמוד-2 בלבד

**אם אובייקט לא תומך בשקיפות (טקסט) — לא הצג אותה** בשורה-1, אך **שמור את הסדר** כדי שכפתורים אחרים יישארו באותה עמדה.

## implementation

**קוד:**

```js
function buildCtxBar(type) {
  const row1 = [];
  const row2 = [];
  
  // ★ כל הקשר
  if (type !== 'text') {  // טקסט לא צריך שקיפות
    row1.push(mkOpacitySlider());
  }
  
  if (type !== 'text') {  // טקסט לא צריך ריבוד
    row1.push(mkLayeringButtons());
  }
  
  // ★ ייחודי להקשר
  switch(type) {
    case 'text':
      row1.push(...mkTextTools());
      break;
    case 'image':
      row1.push(...mkImageTools());
      break;
    case 'shape':
      row1.push(...mkShapeTools());
      break;
    // ...
  }
  
  // ★ עמוד-2 לכל הקשר
  row2.push(mkLockButton(), mkDeleteButton());
  
  render(row1, row2);
}
```
