## TL;DR — שלוש נקודות מפתח

- **✅ רוב הבאגים ברמת-UI (תמונות, קפיצות, מיקום) תוקנו** בסשנים האחרונים (2026-06-22 עד 2026-06-23)
- **❌ בעיות ארכיטקטוניות נותרו:** localStorage מלא (צריך IndexedDB), undo/redo של free-objs (by design), TTS עברי (בהחלטה)
- **❌ שיפורי טבלאות עדיין פתוחים:** table-layout:fixed, merge/split תאים, float סביב טבלה (לא בעדיפות כרגע)

## Key Findings (ממצאים עדכניים)

1. **✅ באגי UI (תמונות, בחירה, מיקום) תוקנו כבר** — ראה [BUGS-STATUS-2026-06-24.md](BUGS-STATUS-2026-06-24.md)
2. **✅ localStorage מלא — נפתר!** `mwDB` = שכבת IndexedDB מלאה (DB `myword2_idb`) + fallback + migration. אומת חי 2026-06-25. ❌→✅
3. **⏳ TTS עברי = בהחלטה** — איזה ספק? Azure מומלץ; Whisper זו STT לא TTS
4. **✅ Pagination re-entrant תוקן** — וגם mousemove throttle + sanitizing
5. **❌ מיזוג צורות אמיתי (boolean ops) עדיין לא ממומש** — דרוש Paper.js או Clipper.js

## ⚠️ אזהרות חזקות ל-Claude Code

1. **localStorage מלא = צריך IndexedDB** — זה **לא** bandaid של gzip או truncation. דרוש שינוי ארכיטקטוני.
2. **כל שינוי pagination = regression tests חובה** בטבלאות, תמונות float, וצורות.
3. **RTL+LTR בכל תיקון** — זו הברירת מחדל של MyWord.
4. **Undo/redo של free-objs = פתור מלא או לא בכלל** — חלקי גרוע יותר מלא בצדק.
5. **Whisper זה STT לא TTS** — אם ראית זה בקוד, זו טעות ארכיטקטונית.
