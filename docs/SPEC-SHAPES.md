## A. גלריית צורות — עיצוב מחדש וסט אייקונים

**מצב נוכחי בקוד:**
`openShapePicker()` בונה גלריה `.shape-picker` (רוחב 392px, ~1772) מקובצת ל-6 קטגוריות: גאומטריות, מיוחדות, חצים, קווים, דיאגרמות, מחברים. כל פריט = כפתור עם תצוגה-מקדימה SVG (`_buildShapeSVG` ב-`#c7d2fe`/`#4338ca`) + תווית. הצורות מוגדרות ב-`SHAPE_DEFS` כ-polygons/paths ב-viewBox `0 0 100 100`, `stroke-width:4`, `vector-effect:non-scaling-stroke`. יש כותרות-קטגוריה (`.sp-cat`) עם קו-מפריד אחרי, ותיאורי-קטגוריה (`.sp-desc`) לדיאגרמות/מחברים.

**מה לא נוח (דיווח המשתמש):**
1. **"הצורות מכוערות"** — חלק מה-`SHAPE_DEFS` בעלי פרופורציות/עיגול-פינות גסים (למשל `heart`, `cloud`, `lightning`, `star6` כשתי משולשים נפרדים שלא מתאחדים יפה). ה-stroke בעובי 4 על viewBox 100 נראה עבה ב-preview קטן.
2. **"הגלריה לא ברורה"** — אין הבחנה ויזואלית חזקה בין קטגוריות; כל הצורות באותו כחול אחיד; אין סינון/חיפוש; ה-preview רקע אחיד-לבן (`.sp-prev` ~1777).

**מצב רצוי:**
1. **שיפור גאומטריית הצורות** (עדכון `SHAPE_DEFS` בלבד — לא משנה את ה-API):
   - `heart`: עקומת בזייה סימטרית וחלקה יותר.
   - `cloud`: 4–5 קשתות עם בליטות אחידות.
   - `star6` (מגן-דוד): שני משולשים שמצטלבים נכון (כיום נראים כשני משולשים).
   - `lightning`/`star5`: לאזן פרופורציות.
   - להוריד `stroke-width` ל-`2.5`–`3` ב-`_buildShapeSVG` (~7263) ל-look עדין יותר (Word משתמש בקו דק).
2. **סט אייקוני SVG אחיד** — כבר נבנה מ-`_buildShapeSVG`; להבטיח `stroke-linejoin:round` בכל הצורות (קיים) ו-`stroke-linecap:round` לקווים/חצים.
3. **שיפור הגלריה (UX):**
   - **שדה חיפוש** בראש הגלריה (`<input class="sp-search">`) שמסנן את הצורות לפי התווית בזמן-אמת.
   - **צבע-פר-קטגוריה** ל-preview: גאומטריות=כחול, מיוחדות=סגול, חצים=ירוק, דיאגרמות=כתום — עדין, לעזור באוריינטציה.
   - `.sp-prev` עם רקע gradient עדין (קיים `#f8fafc→#eef2f7`) — לשמור.
   - hover מוגדל (`transform:translateY(-1px)` קיים) — לשמור.
   - להוסיף **קטגוריית "אחרונות"** (`myword2_recent_shapes` ב-localStorage, עד 8) בראש הגלריה.

**input → output:**
```
לחיצה על כפתור הצורות בסרגל ההוספה → גלריה נפתחת מתחת לכפתור
הקלדה בשדה החיפוש "חץ" → רק צורות עם "חץ"/"ר" בתווית מוצגות
לחיצה על צורה → insertFreeShape(kind) → צורה נוספת כ-free-obj, נשמרת ל"אחרונות"
פתיחה חוזרת → קטגוריית "אחרונות" בראש
```

**מידות/CSS (בסוף ה-`<style>`):**
```css
.shape-picker .sp-search { width:100%; box-sizing:border-box; margin:0 0 8px;
  padding:8px 10px; border:1px solid var(--border); border-radius:9px;
  font-size:12.5px; font-family:inherit; direction:rtl; }
.shape-picker .sp-search:focus { outline:none; box-shadow:0 0 0 2px rgba(99,102,241,.3); }
/* צבע-פר-קטגוריה ל-preview: דרך data-cat על ה-button או class על ה-svg fill */
.shape-picker .sp-grid.cat-geo  button svg [fill]:not([fill="none"]) { fill:#c7d2fe; }
.shape-picker .sp-grid.cat-arrow button svg [fill]:not([fill="none"]) { fill:#bbf7d0; }
```
> מידות בסיס נשמרות (392px רוחב, grid `repeat(4,1fr)`, svg 40×40, max-height 76vh+scroll).

**איך Word:** Insert > Shapes פותח גלריה מקובצת (Lines / Rectangles / Basic Shapes / Block Arrows / Flowchart / Stars and Banners / Callouts), עם "Recently Used Shapes" בראש. הצורות שם מינימליסטיות עם קו דק. זה היעד.

**שלבי מימוש:**
1. עדכון נתוני `SHAPE_DEFS` (~7204) לצורות שצוינו — שינוי `points`/`d` בלבד, לא מבנה.
2. `_buildShapeSVG` (~7263): `stroke-width` 4→3.
3. `openShapePicker` (~7416): הוספת `<input class="sp-search">` + לוגיקת סינון; הוספת קטגוריית "אחרונות" מ-localStorage; `insertFreeShape` מעדכן את הרשימה.
4. CSS בסוף ה-`<style>`.

**בדיקה למרקוס:** הגלריה נפתחת; חיפוש מסנן; בחירת צורה מוסיפה `.free-obj` עם SVG תקין; "אחרונות" מתעדכן; הצורות החדשות מתרנדרות ללא שגיאות.

## B. ייבוא צורות מבחוץ (SVG / תמונה) — ✅ קיים, לוודא + לחזק

**מצב נוכחי בקוד:**
**כבר מומש.** כפתור `.sp-import` בראש הגלריה (~1750, JS ~7453) "ייבא צורה / SVG מהמחשב". `importShapeFromFile()` (~7358) פותח `<input type="file" accept="image/*,.svg">`, קורא כ-DataURL, ומעביר ל-`_buildImageObjFromSrc(src)` → נוצר אובייקט-תמונה חופשי תקין (נשמר/נטען כמו תמונה רגילה).

**מה לוודא / לחזק (דיווח המשתמש ביקש "ייבוא"):**
- **SVG מיובא נכנס כתמונה (raster-like)** ולא כצורה ניתנת-לעריכה. זה תקין לרוב המקרים, אך כדאי לתעד: ל-SVG אפשר לשמר את הטקסט-SVG כדי לאפשר שינוי צבע מילוי/קו (כמו לצורות מובנות) — שדרוג עתידי אופציונלי.
- **גודל התחלתי הגיוני:** לוודא ש-`_buildImageObjFromSrc` נותן גודל ברירת-מחדל סביר ל-SVG ללא מימדים מוגדרים (למשל 200×200px), ו-`_clamp` נקרא.
- **תצוגה מקדימה לפני הוספה** (אופציונלי): אין כרגע; אפשר להוסיף.

**input → output:**
```
לחיצה על "ייבא צורה / SVG" → דיאלוג קבצים
בחירת logo.svg → נוסף כ-free-obj במרכז העמוד, ניתן לגרירה/שינוי-גודל/שקיפות
בחירת icon.png → אותו זרימה
SVG ללא width/height → מקבל גודל ברירת-מחדל ~200px ולא 0
```

**מצב רצוי:** לרוב קיים. ליטוש:
1. ב-`importShapeFromFile`: אם הקובץ `.svg` — אפשר לקרוא גם כ-`readAsText` ולשמור את ה-markup ב-`data-svg-source` כדי לאפשר בעתיד עריכת-צבע. (לא חובה לסבב זה.)
2. לוודא גודל-ברירת-מחדל ב-`_buildImageObjFromSrc` עבור SVG.

**איך Word:** Insert > Pictures (כולל SVG) — SVG ב-Word נכנס כ-Graphic ניתן-להמרה ל-Shape ולעריכת צבעים. MyWord עושה את החלק הבסיסי (הכנסה); עריכת-צבע ל-SVG מיובא = שדרוג עתידי.

**שלבי מימוש:**
1. בדיקה ב-`_buildImageObjFromSrc` (~6839) שגודל ברירת-המחדל ל-SVG תקין; אם לא — להוסיף fallback.
2. אופציונלי: שמירת `data-svg-source` ל-SVG טקסטואלי.

**בדיקה למרקוס:** ייבוא SVG ו-PNG → נוצר `.free-obj` תקין, נכלא לדף, נשמר ב-`freeObjs`, ונטען מחדש אחרי reload.

## C. פעולות בוליאניות (איחוד / חיתוך / חיבור) — UI בתפריט הצף והרגיל

**מצב נוכחי בקוד:**
**כבר מומש חלקית.** נקודות-כניסה קיימות:
- בגלריה: כפתור `.sp-import` שני "אחד / חתוך צורות שבמסמך" → `window._startShapeCombine()` (~7460).
- בסרגל הצף של צורה: כפתור 🧩 "אחד או חתוך עם צורות נוספות" → `_startShapeCombine(obj)` (~9059).
- `_startShapeCombine` (~8937) נכנס ל**מצב בחירה-מרובה** (`_multiMode`, `multi-sel`), מאפשר לסמן צורות נוספות, ואז לבחור פעולה בסרגל המרובה (`buildMulti`).
- מימוש האיחוד הגאומטרי: `mergeSelectedShapes(objs)` (~7399) → `_mergeShapesToSVG` מאחד את ה-SVG-ים של ≥2 צורות ל-SVG אחד (לפי bbox משותף) ויוצר אובייקט-תמונה חדש.

**מה לא נוח / מה חסר (דיווח המשתמש):**
1. **"איך ה-UI נראה"** — תהליך הבחירה-המרובה לא ברור ויזואלית; המשתמש לא יודע מה לסמן ומה כל פעולה עושה.
2. כיום קיים בעיקר **איחוד (Union)** דרך `_mergeShapesToSVG` (מצרף את כל ה-SVG-ים). **חיתוך (Intersect)** ו**חיסור (Subtract)** אמיתיים (בוליאני-נתיב) **לא** מיושמים — רק שכבוב SVG.

**מצב רצוי — UI ברור:**
- **לאחר `_startShapeCombine`**: סרגל-מרובה (`buildMulti`) מציג **קבוצת כפתורי-פעולה בוליאנית** עם אייקוני-תצוגה ברורים (שתי צורות חופפות עם החלק הרלוונטי מודגש), כמו ב-Word:
  | פעולה | אייקון | תיאור | מצב מימוש |
  |---|---|---|---|
  | **איחוד** (Union) | שתי צורות ממוזגות מלאות | מאחד לכדי צורה אחת | ✅ `mergeSelectedShapes` |
  | **חיבור/קיבוץ** (Group) | מסגרת סביב שתיים | משאיר נפרד אך זז יחד | להוסיף (קל) |
  | **חיתוך** (Intersect) | רק החפיפה | משאיר רק את החלק המשותף | ⏳ דורש clipPath/בוליאני |
  | **חיסור** (Subtract) | צורה עם חור | מסיר את החפיפה מהראשונה | ⏳ דורש mask/בוליאני |
- **hint מנחה** בעת הכניסה למצב: "סמן 2+ צורות → בחר פעולה: איחוד / חיתוך / חיסור / קיבוץ" (חלקית קיים — לחזק).
- **תצוגה ויזואלית של הבחירה**: צורות שנבחרו מקבלות `.multi-sel` outline ברור (קיים) + ספירה ("2 צורות נבחרו").
- **מימוש חיתוך/חיסור** (כשאין boolean-path library — אסור תלויות, §1):
  - **חיתוך** דרך SVG `<clipPath>`: לרנדר את צורה A עם `clip-path` של צורה B → רק החפיפה נראית.
  - **חיסור** דרך SVG `<mask>`: צורה A עם mask שבו B שחור → B "מחורר" מ-A.
  - שתיהן ניתנות-מימוש ב-SVG טהור ללא ספרייה, בדומה ל-`_mergeShapesToSVG`.

**input → output:**
```
בחר צורה → 🧩 בסרגל הצף → מצב בחירה-מרובה, hint מופיע
לחץ צורה שנייה → "2 צורות נבחרו", סרגל מרובה מציג: [איחוד][חיתוך][חיסור][קיבוץ]
לחיצה "איחוד" → mergeSelectedShapes → SVG אחד ממוזג במקום השתיים
לחיצה "חיתוך" → SVG עם clipPath, רק אזור החפיפה גלוי
לחיצה "חיסור" → SVG עם mask, A פחות B
לחיצה "קיבוץ" → השתיים נשמרות אך מקבלות data-group משותף וזזות יחד
Escape / "סיום" → יציאה ממצב בחירה-מרובה (קיים ~9539)
```

**מידות/CSS (בסוף ה-`<style>`):**
```css
.bool-op-btn { display:inline-flex; flex-direction:column; align-items:center; gap:3px;
  min-width:46px; padding:6px 4px; }
.bool-op-btn svg { width:24px; height:18px; }
.bool-op-btn .lb { font-size:9px; }
```

**איך Word:** Shape Format > Merge Shapes מציג חמש פעולות עם אייקוני-תצוגה: Union, Combine, Fragment, Intersect, Subtract — מופעלות רק כשנבחרו 2+ צורות. MyWord כבר מאמץ את העיקרון; היעד הוא להשלים את חיתוך/חיסור ולהבהיר את ה-UI.

**שלבי מימוש:**
1. ב-`buildMulti` (סרגל הבחירה-המרובה): כשכל הנבחרים הם צורות (≥2) → להוסיף קבוצת `.bool-op-btn` עם 4 פעולות + אייקוני-SVG.
2. איחוד: קריאה ל-`mergeSelectedShapes` הקיים.
3. חיתוך/חיסור: שתי פונקציות חדשות `_intersectShapesToSVG`/`_subtractShapesToSVG` במתכונת `_mergeShapesToSVG` — בונות SVG עם `<clipPath>`/`<mask>` במקום שכבוב פשוט.
4. קיבוץ: לתת `data-group=<id>` משותף + לוגיקת גרירה-יחד ב-`_makeDraggable` (אם קיים group → להזיז את כל הקבוצה).
5. חיזוק ה-hint + מונה-בחירה.

**בדיקה למרקוס:** 2 צורות חופפות → איחוד יוצר SVG אחד; חיתוך משאיר רק חפיפה; חיסור יוצר חור; כל התוצאות הן `.free-obj` תקינים שנשמרים ונטענים; הפעולות מושבתות כשפחות מ-2 צורות.
