# SPEC-UX-HIDDEN-BUTTONS-DISCOVERY — גילוי כפתורים בעמוד-2

**קטגוריה:** Discoverability · UX  
**חומרה:** 🟠 גבוה (משתמשים מפספסים פונקציות שקיימות)  
**מיקום ב-UI:** 
- סרגל הבית — קבוצות עם `▾` (dropdown) שמסתיר אפשרויות
- סרגל הוספה — ▾ לטבלה, תמונה, צורות
- סרגל הצף — `#ctxMore` עם עמוד-2 חבוי

---

## מה קיים עכשיו

**סדר הכפתורים בסרגל הבית:**
```
[שם גופן]  [גודל]  [B] [I] [U] [S] [סמן] [צבע] [צבע-רקע]
[יישור ×4]  [רשימות]  [ביטול] [ביקור]

▾ "עוד אפשרויות" — עמוד-2 מוסתר:
  - ניקה עיצוב
  - מברשת עיצוב
  - סופר/תחתי
  - … 5 פריטים נוספים
```

**בעיה:**
1. **הכפתור ▾ קטן מדי** — לרובות, נראה כ"מתגי" ללא משמעות צפוי
2. **"עוד אפשרויות" לא ברור** — המשתמש לא יודע **כמה** אפשרויות חבויות
3. **לא יש label/badge** — לא ברור שיש 8+ כפתורים בעמוד-2

---

## המשתמש חושב

1. "אני מחפש 'ניקה עיצוב' — לא מוצא בשורה-1"
2. "יש פה חץ קטן? בטוח זה חשוב?" → מדלג עליו
3. "הרי יש Word 'Clear Format' בעמוד-1 של Ribbon!"

## הצעה — שלוש אפשרויות (בסדר עדיפות)

### אפשרות A: Badge עם מספר הכפתורים (⭐ מומלץ)

```html
<button id="moreBtn" class="ctx-arrow" title="עוד 8 אפשרויות">
  <span class="ico">⋮</span>
  <span class="lbl">עוד</span>
  <span class="more-badge">+8</span>  <!-- בולט, ברור שיש עוד -->
</button>
```

**CSS:**
```css
#moreBtn .more-badge {
  position: absolute; top: -6px; right: -6px;
  background: var(--danger); color: #fff;
  border-radius: 50%;
  width: 20px; height: 20px;
  display: flex; align-items: center; justify-content: center;
  font-size: 11px; font-weight: 700;
}
```

**תוצאה:**
- 🔴 חיווי ברור שיש עוד
- משתמש ניגש אליו מיד

---

### אפשרות B: טיפול בסרגל-הבית — הוצאת הכפתורים הנדירים מ-עמוד-1

**הזיהוי של "נדיר":**
- ✅ B/I/U/S (מעפ החלטה-מוצר, **משתמשי ליבה משתמשים בקיצורים**)
- ✅ יישור ×4 (קלסטר אחד, משתמשים משתמשים בקיצורים Ctrl+L/R/E/J)
- ❌ ניקה עיצוב (בחירה מהתפריט, **משתמש יתקוף**... אבל **לא בשורה-1** ב-Word!)
- ❌ מברשת עיצוב (חד-פעמי לעיתים רחוקות, יכול להיות עמוד-2)
- ❌ סופר/תחתי (5% מהמשתמשים משתמשים)

**אפשרות: הוצא ל-עמוד-2:**
- מברשת עיצוב
- ניקה עיצוב ← **תכנס מחדש בקליק יד-ראשי?** (ר' SPEC-RCMENU)
- סופר/תחתי
- מעיל רישיות
- צל טקסט

**עדכון סרגל בית:**
```
[שם גופן]  [גודל]  [B] [I] [U] [S]  [סמן] [צבע] [צבע-רקע]
[יישור ×4]  [רשימות]  [ביטול] [חזור]  [עוד ⋮]
```

**כלל:** שורה-1 = תדר-גבוה (B/I/U/S הם בקיצורים!) + יישור + צבע.  
עמוד-2 = תדר-נמוך + מתקדם.

## בחירה: **אפשרות A + B**

1. **Badge בו"+8"** → `▾ עוד +8`
2. **הזז "ניקה עיצוב" ל-עמוד-2** (משתמש יעדיף קליק-ימני לכל זאת)
3. **הוסף tooltip:**
   ```
   title="עוד אפשרויות (ניקה עיצוב, מברשת עיצוב, סופר, תחתי, מעיל רישיות)"
   ```

## השוואה ל-Word

Word v365 (בית):
- **שורה-1:** גופן, גודל, B/I/U, **צבע טקסט**, צבע הדגשה, מחיקה עיצוב
- **▾ "עוד":** סופר, תחתי, צל, עיצוב מתקדם

## step-by-step

### טפל בבית
1. בהצגה: סמן "עוד אפשרויות" → תוכל לראות "+8 נוסף"
2. לחץ עליו → נפתח תפריט בעמוד-2
3. בחר "ניקה עיצוב" → סמן הטקסט נמחק

### טפל בסרגל הוספה
צורות: `▾ צורות | +15 צורות נוסף` (אל תחפש אותן יד-ידנית)

## כלל כללי

**לכל `▾ עוד` שמוסתר 3+ פריטים:**

- **Tooltip:** רשימה קצרה של הפריטים הראשונים ("… ועוד 8")
- **היציא:** בקטגוריה שונה מ-עמוד-1

## implementation

1. **בסרגל הבית:** הוסף `<span class="badge">+8</span>` ליד `#moreBtn`

3. **בעמוד-2:** התווה את הפריטים בקטגוריות (מחיקה, מברשת, תחתוני, טקסט)
