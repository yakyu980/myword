# איך להשתמש במסמכים האלה עם Claude Code

## 📁 מבנה תיקיות שצריך ליצור בפרויקט
```
MyWord/                        ← תיקיית הפרויקט שלך
│
├── CLAUDE.md                  ← ⭐ Claude Code קורא אותו אוטומטית!
├── MyWord-v2.html             ← הקובץ הראשי שלך
│
└── docs/
    ├── PAGE_RULES.md
    ├── TEXT_FLOW.md
    ├── IMAGES.md
    ├── TABLES.md
    ├── TOOLBAR.md
    ├── PASTE.md
    ├── DESIGN.md
    └── BUGS.md
```
---
## 🚀 שלבי התקנה
### שלב 1 — צור תיקיית docs
בתיקיית הפרויקט שלך (ליד MyWord-v2.html):
```
mkdir docs
```
### שלב 2 — העתק את הקבצים
- `CLAUDE.md` → ליד `MyWord-v2.html` (באותה תיקייה!)
- כל קבצי ה-docs → לתוך תיקיית `docs/`
### שלב 3 — פתח Claude Code בתיקייה הנכונה
```bash
cd /path/to/MyWord
claude
```
Claude Code יזהה את `CLAUDE.md` ויקרא אותו **אוטומטית** בתחילת כל session.
---
## 💬 פרומפט לכל תיקון / פיצ'ר חדש
**העתק את זה בכל פעם שאתה רוצה משהו:**
```
לפני שאתה מתחיל:
1. קרא את CLAUDE.md במלואו
2. קרא את docs/PAGE_RULES.md — וודא שהשינוי לא מפר אף חוק ✅
3. קרא את docs/[שם הקובץ הרלוונטי].md
המשימה:
[תאר מה לתקן או לבנות]
אל תכתוב קוד עד שהצגת תוכנית קצרה וקיבלת ממני אישור.
```
---
## 📋 טבלת בחירת MD לפי משימה
| אני רוצה לתקן / לבנות... | קרא את... |
|--------------------------|-----------|
| גודל דף, מרגינים, header/footer | `PAGE_RULES.md` (תמיד!) |
| טקסט, Enter, ריווח שורות, כותרות | `TEXT_FLOW.md` |
| תמונה — הוספה, גרירה, מצבים | `IMAGES.md` |
| טבלה — יצירה, עריכה, מחיקה | `TABLES.md` |
| כפתור בסרגל, קיצור מקלדת | `TOOLBAR.md` |
| העתק/הדבק/גזור | `PASTE.md` |
| צבעים, גופנים, זום, z-index | `DESIGN.md` |
| לפני תיקון באג — בדוק אם מוכר | `BUGS.md` |

## ⚡ דוגמאות לפרומפטים מוכנים
**תיקון תמונה לפי מיקום סמן:**
```
קרא: CLAUDE.md + docs/PAGE_RULES.md + docs/IMAGES.md (חוק 11)
משימה: תמונה מוכנסת תמיד ב-left:60px top:60px — תקן כך שתופיע ליד הסמן.
אל תכתוב קוד עד שהצגת תוכנית.
```
**הוספת מיזוג תאים:**
```
קרא: CLAUDE.md + docs/PAGE_RULES.md + docs/TABLES.md
משימה: הוסף אפשרות מיזוג תאים (colspan) בטבלה — לחצן בתוך toolbar הטבלה.
אל תכתוב קוד עד שהצגת תוכנית.
```
**הדבקת תמונה מ-clipboard:**
```
קרא: CLAUDE.md + docs/PAGE_RULES.md + docs/PASTE.md (חוק 6) + docs/IMAGES.md
משימה: Ctrl+V על תמונה שצולמה (screenshot) יכניס אותה כ-free-obj.
אל תכתוב קוד עד שהצגת תוכנית.
```
