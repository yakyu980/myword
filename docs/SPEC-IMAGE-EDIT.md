## עקרון-על משותף לשלושת הפאנלים
- `_imgEnsureOrig(img)` שומר `img.dataset.origSrc = img.src` **פעם אחת בלבד** (בפעם הראשונה שנפתח פאנל-כלשהו על התמונה) — מאפשר "שחזר תמונה מקורית" גם אחרי כמה עריכות רצופות (מסננים→הסרת-רקע→מסננים שוב).
- `_serializeObj`/`_deserializeFreeObjs` שומרים/משחזרים `imgOrigSrc` (§6) — השחזור-למקור שורד שמירה/רענון/טעינת-מסמך.
- כל הכפתורים חיים בשני מקומות: (1) סרגל-האובייקט הישן (`_addToolbar`) — 🌗/✂️ בלבד; (2) "עוד" (`moreBtn`) של הסרגל הצף לתמונה (`buildImage` ctxBar) — כל 3 הפאנלים + מסגרת. חוק 2-השורות (§8) נשמר — אף כפתור לא בשורה הראשית.
- החל מ-2026-07-08 (שלב 2) גם דרך לשונית-ההקשר **"🖼️ עיצוב תמונה"** — ר' `SPEC-CTX-TABS.md`.

## פאנל 1 — מסננים (`openImageFiltersPanel(anchor, obj)`, ~18393)
**מטרה:** בהירות / ניגודיות / רוויה.

| שלב | Input → Output |
|---|---|
| פתיחה | קורא `_imgEnsureOrig`; קורא ערכים נוכחיים מ-`img.dataset.brightness/contrast/saturate` (ברירת-מחדל 100 לכולם) |
| גרירת-מחוון | preview חי: `img.style.filter = 'brightness(X%) contrast(Y%) saturate(Z%)'` — **CSS בלבד, זמני**, לא נשמר עדיין |
| "בטל" | `img.style.filter = _imgCurrentCssFilter(img)` (חוזר לערך-השמור הקודם ב-dataset, לא ל-0) → סוגר פאנל |
| "אישור — החל" | `_historyRecord()` → `_bakeImageFilter(img, cssFilter, done)`: מצייר את התמונה על `<canvas>` בגודל-טבעי עם `ctx.filter = cssFilter`, ואז `img.src = canvas.toDataURL('image/png')` (**תמיד PNG**, שומר alpha אם קיים) → `img.dataset.brightness/contrast/saturate` מתעדכנים לערכים החדשים, `img.style.filter=''` (הפילטר-החי מתנקה כי הוא כבר "נצרב" לפיקסלים) → `scheduleSave()` + `updatePagination()` |
| "שחזר תמונה מקורית" | `img.src = img.dataset.origSrc`; `img.style.filter=''`; מוחק `dataset.brightness/contrast/saturate` |

**קריטי:** ה-bake הוא **הכרחי** — `_serializeObj` שומר רק `img.src` (§6), לא CSS חי. בלי bake, מסננים לא היו שורדים רענון/ייצוא.

## פאנל 2 — הסרת-רקע (`openBgRemovePanel(anchor, obj)`, ~18505)
**מטרה:** chroma-key אוטומטי + מברשת ידנית לתיקון-עדין ("מקצועי וידני, לפי צורך" — בקשת-משתמש מקורית).
**תנאי-כניסה:** `img.complete && img.naturalWidth` (לא נפתח על תמונה שעדיין נטענת).

| רכיב | התנהגות |
|---|---|
| קנבס-עבודה | גודל **טבעי** של התמונה (לא מוקטן פנימית — CSS בלבד מקטין ויזואלית; קואורדינטות תמיד מדויקות-בפיקסל) |
| `origData` | עותק-מקור של `getImageData` בזמן-פתיחה — משמש למברשת "שחזר" |
| **סף-סבילות** | מחוון 0–100, מנורמל ל-`tol/100 * 441.7` (441.7 ≈ `sqrt(255²*3)`, מרחק-RGB מקסימלי) |
| **מצב 🎯 בחר-צבע (chroma)** | קליק על פיקסל → `_applyChromaKey(px,py)`: קורא צבע-הפיקסל, ואז לכל פיקסל בתמונה שמרחקו-Euclidean-RGB ≤ סף → `alpha=0` |
| **מצב 🧽 מחק (erase)** | גרירה מוחקת (`alpha=0`) בעיגול סביב הסמן, רדיוס = מחוון-גודל-מברשת (4–80px) |
| **מצב ↩️ שחזר (restore)** | גרירה מחזירה `alpha` מ-`origData` (מבטל מחיקה קודמת באזור הזה, **לא** את ה-chroma-key — chroma עצמו לא נשמר כ"פעולה" נפרדת, רק כתוצאת-alpha על הקנבס הנוכחי) |
| **✨ הסרה אוטומטית** (2026-07-13) | `_autoRemoveBg`: צבע-רקע-ייחוס = ממוצע פיקסלי-הקצה האטומים → flood-fill מכל 4 הקצוות פנימה בטווח-הסבילות. מסיר רק רקע **רציף שמחובר לקצה** — אובייקט במרכז נשאר. אופליין, בלי AI |
| **מצב 📌 שמור (keep)** (2026-07-13) | מסמן `keepMask` (ירוק, על קנבס-overlay נפרד שאינו נצרב) — ההסרה-האוטומטית/chroma מדלגות על פיקסלים מוגנים ולא עוברות דרכם |
| רקע-שחמט (2026-07-13) | `background-image` משובץ מאחורי הקנבס — רואים בזמן-אמת מה נהיה שקוף |
| **✂️ חתוך לגבולות האובייקט** (2026-07-20) | תיבת-סימון `#_bgCropChk`, **דלוקה כברירת-מחדל**. ב"החל": `_imgOpaqueBounds` (גבולות `alpha>8`; `null`=הכל-שקוף→מדלגים+hint) → `_imgCropToBounds` חותך את השוליים השקופים **ומכווץ את ה-box באותה פרופורציה** (`left += W*x0/nw` וכו') — האובייקט לא זז ולא משנה גודל על המסך, רק המסגרת/הידיות מתהדקות סביבו. לאובייקט מסובב מרכז-החיתוך עובר את אותה רוטציה סביב המרכז הישן. הגיאומטריה שלפני-החיתוך נשמרת ב-`dataset.preCropBox` (סריאליזציה: `imgPreCrop`) |
| "החל" | (עם חיתוך אם מסומן →) `img.src = canvas.toDataURL('image/png')` (שומר alpha) → `_clamp(obj)` אם נחתך → `scheduleSave()` + `updatePagination()` |
| "בטל" | סוגר פאנל בלי לגעת ב-`img.src` |
| "שחזר תמונה מקורית" | כמו בפאנל-1 — חוזר ל-`origSrc` **+ `_imgRestorePreCrop(obj)`** מחזיר את הגיאומטריה שלפני-החיתוך (כל 3 מסלולי-השחזור: פאנל-1/פאנל-2/ריבון `imgformat`) |

**תרחיש-בדיקה מדויק (מאומת חי):** תמונת-בדיקה אדומה עם ריבוע-כחול במרכז → קליק על אדום → `alphaRed=0, alphaBlue=255` → "החל" → `img.src` הוא PNG חדש (שונה מהמקור, שקוף באדום).
**תרחיש-חיתוך (מאומת חי 2026-07-20):** תמונה 100×100, ריבוע אטום ב-(30,20) בגודל 40×25, box התחלתי 100×100 ב-(38,38) → אחרי הסרה+חיתוך: פיקסלים 40×25, box 40×25, `left/top` = 68/58 (= 38+100·30/100, 38+100·20/100); "שחזר מקורית" מחזיר 100×100 ב-(38,38).
**⚠️ בבדיקות:** `insertFreeImage()` לא מקבל src (פותח בורר-קבצים) — להשתמש ב-`_buildImageObjFromSrc(src)`.

## פאנל 3 — מסגרת לתמונה (`openImageBorderPanel(anchor, obj)`, ~18688)
**מטרה:** מסגרת + פינות-מעוגלות — **לא bake**, CSS ישיר.
**דפוס:** פורט מ-`openCellBorderPanel` (טבלה) + `selRadius` נוסף. מחיל על `.free-img-wrap` (לא על `.free-obj` כולל handles) כדי שהמסגרת תעטוף בדיוק את התמונה.

| שדה | טווח/ערכים |
|---|---|
| צבע | 8 swatches קבועות |
| עובי | px |
| סגנון | solid/dashed/dotted/... |
| **רדיוס** (פינות-מעוגלות) | px — `wrap.style.borderRadius` |

נשמר עם ה-style הרגיל של `.free-img-wrap` — אין שדה-dataset ייעודי, אין bake.

## מלכודות ידועות
- **לא לקרוא ל-`_bakeImageFilter` על תמונה שעדיין לא `img.complete`** — `naturalWidth`/`naturalHeight` יהיו 0, הקנבס ייצא ריק.
- **הסרת-רקע דורשת `willReadFrequently: true`** בקונטקסט (`ctx = cv.getContext('2d', {willReadFrequently:true})`) — נדרש לביצועים כש-`getImageData` נקרא הרבה (chroma-key + כל paint-event במברשת).
- `outType` ב-`_bakeImageFilter` **תמיד PNG** (גם אם המקור היה JPEG) — כדי לא לאבד שקיפות שנוספה בהסרת-רקע קודמת.
